Database user, database name, and password come from Secret {{ include "agentmail.secretName" . }}, written by vaultwarden-kubernetes-secrets.
Before the pods can start:

1. Install the sync service and point it at your Vaultwarden server:
     helm upgrade -i vaultwarden-kubernetes-secrets \
       oci://ghcr.io/antoniolago/charts/vaultwarden-kubernetes-secrets \
       --version 2.1.0 \
       -n vaultwarden-kubernetes-secrets --create-namespace \
       --set namespace.create=true \
       --set-string env.config.VAULTWARDEN__SERVERURL="$VAULTWARDEN_SERVER_URL"
2. Create a Vaultwarden item whose namespaces field includes {{ .Release.Namespace }} and whose secret-name is {{ include "agentmail.secretName" . }}.
3. Add custom fields {{ .Values.vaultwarden.keys.user }}, {{ .Values.vaultwarden.keys.postgresUser }}, {{ .Values.vaultwarden.keys.database }}, {{ .Values.vaultwarden.keys.postgresDatabase }}, {{ .Values.vaultwarden.keys.passwordB64 }}, and {{ .Values.vaultwarden.keys.postgresPassword }}. {{ .Values.vaultwarden.keys.passwordB64 }} is standard base64. {{ .Values.vaultwarden.keys.postgresPassword }} is the plaintext password.
